# Autonomous Research Team for Applied AI

A Pi-based research team for reproducible LLM and agentic-systems experiments. The main Pi session is the Research Lead; `pi-subagents` runs the fixed specialists and any separately approved pool profiles. Beads owns operational tasks. The project ledger preserves authorization, execution evidence, acceptance, and review decisions.

- [Design archive](blueprint-v1.md) — retained for historical tracking and study; it is not a runtime dependency or operational authority
- [Quickstart and operations runbook](tools/research-ops/README.md) — initialize, plan, test, and enable a verified deployment
- [Development tracker](todos.md) — completed work and remaining milestones

The local tools are runnable now. Production delegation requires live verification of the selected models, runtime confinement, and restart recovery; a fixture test is not that verification. The default launcher starts in planning-only mode.
